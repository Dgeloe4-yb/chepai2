# chepai2 Edge Architecture

## Product goal (keep simple)

Per video stream, detect and reason about:

1. **Vehicle type** — COCO pretrained YOLO (`car` / `bus` / `truck`), **full frame**
2. **Plate color** — custom YOLO: `plate_blue` vs `plate_green` on **each vehicle crop** (global, no parking gate)
3. **Mini-ad** — custom YOLO on **drawn ad ROI crop** (not full frame when ROI present)
4. **Park align (停正)** — calibrate plate-center vs vehicle-center offset from a full-row straight-park photo; alarm `bad_park` when `|dx - dx0|` exceeds threshold
5. **Dual slot (占两车位)** — draw parking ROIs; alarm `dual_slot` when one vehicle covers ≥2 slots above `dual_slot_min_ratio`
6. **Bus bay sedan** — draw bus ROIs; alarm `car_in_bus_slot` when a sedan occupies a bus-only bay

Do **not** merge these into one model. Charging-gun detection is **abolished**.

Optional later: HyperLPR3 for plate **text** OCR; plate color is a separate detector.

## Runtime (production only)

- Boot: `chepai-edge.service` → `python -m chepai_edge.main`
- Camera / ROI config: persisted locally (`edge_config.json`); Flutter client writes via Local API on `:8765`.
- Cloud backend: alert upload only (`POST /api/alerts`); unreachable backend does not block startup.
- Embeds local HTTP API (`CHEPAI_LOCAL_API=1`, port `8765`) for Flutter client:
  preview frames from production workers, ROI CRUD, park_align calib, on-demand infer.
- Client default: `http://chepai-rk3588:8765` (production local API only; no debug service).

## Agent rules

1. Keep three models separate; gun is gone.
2. Vehicle + plate = global; mini_ad = ROI crop when `kind` in `{ad,mini_ad,detect}`.
3. `bad_park` = plate-align only; `dual_slot` = multi parking ROI; `car_in_bus_slot` = sedan in bus ROI.
4. Preserve mini-ad dedicated infer thread.
5. Large data on D:; don't commit `.venv` / datasets / secrets.
6. No separate debug mode on IPC — client talks to production local API only.

## Three-model runtime (keep parallel mini_ad thread)

| Model | Weights | Scope | Classes / role |
|-------|---------|-------|----------------|
| Vehicle | `yolov8n.pt` | full frame | car, bus, truck |
| Plate color | `plate_color.pt` | every vehicle bbox | plate_blue, plate_green |
| Mini-ad | `mini_ad.pt` | **ad ROI crop** (else full frame) | guang_gao / mini_ad |

`FramePipeline` keeps `ThreadPoolExecutor(thread_name_prefix="mini-ad-infer")` so mini_ad runs concurrently with vehicle→plate. Do not collapse this when editing.

## Park align (no parking polygons)

1. Take one photo with the row **full** and all cars **straight**.
2. `debug_image.py --calib that.jpg` → writes `weights/park_align.json` anchors `(x_norm, dx0, dy0)`.
3. At runtime: for each vehicle with a plate, pick nearest anchor by `x_norm`, if `|dx-dx0| > dx_threshold` → `bad_park`.

## Events

| event | meaning |
|-------|---------|
| `oil_car` / `possible_oil_block` | blue plate / fuel |
| `mini_ad` | ad detected in ad ROI |
| `bad_park` | plate-align deviation (停正失败) |
| `non_sedan` | bus/truck |
| `dual_slot` | vehicle box covers ≥2 parking ROIs (each ≥ `dual_slot_min_ratio` of vehicle area) |
| `car_in_bus_slot` | sedan (`car`) occupies a bus-only ROI (`kind=bus`) |

## Parking ROIs (for dual_slot only)

- Draw `kind=parking` polygons (client / `debug_image.py`).
- Need **≥2** parking ROIs; overlap metric = `intersection(vehicle, slot_aabb) / area(vehicle)`.
- Default threshold `dual_slot_min_ratio=0.15` (env/rules). Do **not** use parking IoU for `bad_park` (停正仍用 plate-align).
- Plate color / vehicle remain **global** (no parking gate).

## Bus ROIs (轿车占公交位)

- Draw `kind=bus` polygons for bus charging / bus-only bays.
- If COCO class `car` (id=2) covers a bus ROI ≥ `bus_slot_min_ratio` → alert `car_in_bus_slot`.
- `bus` / `truck` in bus bay do **not** trigger this alert (may still trigger `non_sedan`).
